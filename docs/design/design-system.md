# Our Wedding Roll Design System

## Direction

Editorial wedding-film character with a warm ivory background, near-black ink, restrained burgundy actions, sage success states, elegant serif display type, and disciplined sans-serif controls.

## Tokens

- Background: `#f7f3ed`
- Surface: `#fffdf9`
- Ink: `#171512`
- Muted ink: `#6f6961`
- Burgundy: `#8f1f35`
- Burgundy dark: `#681426`
- Sage: `#2f7d4a`
- Hairline: `#ddd7cf`
- Radius: 12px controls, 18px media, 24px sheets
- Motion: 160–220ms ease-out; disabled when reduced motion is requested

## Screens

- Guest welcome: photographic upper field, large serif title, bottom consent sheet.
- Camera: full-bleed stream, minimal top controls, preset filmstrip, large shutter.
- Confirmation: single dominant portrait with Retake and Use Photo.
- Gallery: open two-column mobile grid, name and heart count, fixed bottom navigation.
- Organizer: open desktop shell with compact summary, ranked table, moderation rail.

## Copy lock

Primary brand: “Our Wedding Roll”. Guest actions: “Enter the camera”, “Retake”, “Use Photo”, “Gallery”, “Camera”. Organizer actions: “Pause uploads”, “Close voting”, “Export all”.
